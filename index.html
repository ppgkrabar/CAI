Pengaturan Koneksi API Google Apps Script

Aplikasi saat ini berjalan menggunakan Mode Demo LocalStorage. Untuk menghubungkan dengan Google Sheets asli, masukkan URL Web App Google Apps Script Anda di bawah ini:

Panduan Pemasangan GitHub Pages & Google Sheets

  1. Buat Google Spreadsheet baru dengan 3 Sheet: DataMaster, DataPresensi, DataAkun.
  2. Buka menu Ekstensi > Apps Script, lalu salin isi file Code.gs ke editor tersebut.
  3. Klik Deploy > Deployment Baru > Pilih Jenis: Aplikasi Web > Akses: Siapa Saja (Anyone).
  4. Salin URL Web App yang dihasilkan dan tempelkan pada form Pengaturan API di atas.
  5. Unggah file index.html, style.css, dan app.js ke repositori GitHub Anda dan aktifkan GitHub Pages.
